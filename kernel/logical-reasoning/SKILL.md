# 逻辑推理（logical-reasoning）
用到：因果推断（causal-inference）；证据与核验（evidence-and-verification）。
用于：手上有材料，正要写下一句带"所以／因此／这说明／建议"的话，或者要写一个靠这种推理撑着的判断或建议。
何时：判的是要落笔的这一句话，不是这个话题。这句不是纯引述，带"所以／因此／这说明／建议"；只交代背景的"因为"也走这一份。
这句话说的是原因、根因或者责任——里面有 导致、造成、使得、根因、归咎、责任在，或者它在说"改 X 会修好 Y／防住 Y"——并且它会导出一个改动或者指向某个人、某个团队时，改走「因果推断」（causal-inference）那一份。

字段三态：填了（带来源）／填不出（带原因和缺的最小证据）／不适用（带依据，例如这句话只写到"观察到"这一级、不再往下判断，`warrant` 和 `counter` 就是不适用）。

走法：

1. 打开材料，把支持这句话的原文抄下来 → 留下 `evidence`：逐字片段加文件路径和行号，或者用户的原话。这句话如果说的是"只有／没有／全部／都"这类把范围数清了的话，还要留下用来数的命令、查过的范围、命令的原始输出，包括查出来是空的那一次。填不出："无法定位原文：因为该文件未提供／打不开，缺……"

2. 写出前提，再写出从前提走到结论的那一步理由。
   怎么做：
   a. 先把要写的那句结论单独抄一行。再把为了得到它、你实际用到的话逐条写出来，一条一句，编号 P1…Pn。做到什么算完成：每条后面都标了它从哪来——"第 1 步的原文"、"公开事实"、还是"我自己加的假设"；标不上来源的那条，改写成"假设：……"。
   b. 逐条查这三样，查完在那条后面留一个记号。①可不可接受：别人不用先信你的结论，肯不肯认这条？肯认的记"可接受"，不肯认的写出它还需要什么才成立。②相不相关：把这条当成假的，结论会不会变？不会变的，从 P 清单里划掉，它只是背景。③够不够：把划剩下的几条全当真，它们合起来是不是已经足以得到结论；不够的，把还差的那句补成一条新前提，或者写"缺口：……"。做到什么算完成：P 清单里每条都有这三个记号，被划掉的不再出现在清单里。
   c. 写从前提走到结论的那一步理由：一句话，说清"具备这几条前提的情形，一般会得到这一类结论"。做到什么算完成：把结论从这句话里删掉，它自己仍然说得清一件事；删掉结论后它什么都没说、或者只是把结论换个词重说一遍，就是绕回来了，重写。
   d. 写这一步理由在什么条件下成立：管哪个范围、哪段时间、哪类对象。再写一句"如果 ___，这一步理由就不成立"，把它当成结论的例外写下来。
   e. 按 d 里的条件给结论加上限定，把范围、时间、程度写进句子里，然后把加了限定的这句话抄下来。
   f. 做不到时：c 里那句理由无论怎么写都得先信结论，或者 b 的第三查补不上那条缺的前提，就停在这里，不写这句判断，只写第 1 步能写的话（观察到／材料显示）。
   → 留下 `warrant`：P1…Pn、从前提走到结论的那一步理由、它在什么条件下成立、带条件和范围的结论。那一步理由要能单独说清楚这些前提为什么够得到这个结论——把结论删掉，它自己仍然成立。填不出："无法给出不循环的理由：因为现有前提只支持……，缺……"

3. 造一个前提全是真的、结论却是假的具体情形；或者找一个同样能产生这份证据的相反解释，再写出一个能把它和你的结论分开的观察。
   怎么做：
   a. 先试反例：把 P1…Pn 全部当成真的，写一个具体情形——里面有人、有时间、有数字或者有文件名——在这个情形里这些前提条条成立，而结论是假的。做到什么算完成：别人拿着你的 P 清单逐条去对，能对上全部前提，同时看到结论不成立。
   b. 想不出来时，按四条常见破法各试一次，试出哪条就把它写成 a 那样的具体情形：①这份证据是不是别的原因也会产生（看到这条日志就断定是这个 bug，可别的东西也会打这条日志）？②我是不是只凭"X 在前、Y 在后"就说了 X 起作用？③我是不是只看了一次运行、一个文件、一句话，就说了整体？④我查完之后是不是只抄了对得上的那几条，没记不对的那些和查空的那次？四条都试不出，写"四条破法都没试出具体情形"。
   c. 反例还是造不出来，就退一步造相反解释：写一句"如果不是我说的这个原因，而是 ___，我手上这份证据同样会长成这样"。做到什么算完成：这个相反解释能产生第 1 步抄下的同一份证据；产生不出来的不算，删掉重写。
   d. 写出把两者分开的那个观察：「如果相反解释是真的，我会看到 ___；如果我的说法是真的，我会看到 ___」。两个空必须不一样。
   e. 去做那个观察，看到什么贴什么，包括查出来是空的那一次；做不了就写做不了、缺什么才能做。
   f. 做不到时：两个空写不出不一样的，就不去做这个观察，把这一项标成"分不开"，并把要写的那句话降回第 1 步的级别，不写"最受支持"。
   → 留下 `counter`：那个反例或相反解释、用来分开两者的观察、做没做、结果是什么。填不出："无法区分 A 与 B：因为两者都预测现有证据，缺……"

## 措辞（按实际走完的步数选）

| 走完 | 才可以写 |
|---|---|
| 第 1 步 | 观察到／材料显示／用户写道 |
| 第 1–2 步 | 在……条件下我判断／我建议 |
| 第 1–3 步 | 在已经查过的解释里，这个最受支持（还不可以写因果词） |

这句话同时也触发「因果推断」（causal-inference）或「证据与核验」（evidence-and-verification）的阶梯时，三处各算一级，按最低的那一级写。

做到了：这句话里每个缺了它结论就变的词，都能指回上面某一步留下的东西；没走到的步都写成了"无法……，缺……"；句子已经降到实际走完的那一级。

为什么：一句话读着顺，不等于手上这几条前提真的足以得到它，所以措辞只能强到你实际走完的那一步。

## 每一步来自哪个方法

- 第 1 步 ← 事后选证据（Texas sharpshooter fallacy）：先看见命中再围着它画靶，所以这一步要求把查过的范围和空结果一起留下，不只留对得上的那几条。
- 第 1 步 ← 外部反馈优先（CRITIC）：工具输出、重新跑一遍、原始日志才算新证据，"我又检查了一遍"不算，所以这一步只收原文和原始输出。
- 第 2 步 ← 前提—理由—带限定的结论（Toulmin 三件套）：这一步把一句话拆成前提、从前提走到结论的那一步理由、成立条件和限定，只写结论或者用结论反过来充当理由都不算走过。
- 第 2 步 ← 前提三查（Godden & Walton 的 cogency）：前提要可接受、相关、充分，所以 b 是逐条查这三样，不是笼统说"前提没问题"。
- 第 3 步 ← 反例法（countermodel）：前提全真而结论假的具体情形找不到，才配说"必然"，所以这一步先造反例，造不出才退到相反解释。
- 第 3 步 ← 四条常见破法（肯定后件、后此谬误、以偏概全、事后选证据）：反例想不出来时，按这四条各试一次，试出哪条写哪条。
